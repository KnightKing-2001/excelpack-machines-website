# BlogCard

Reusable article preview card.

## Usage

```tsx
<BlogCard
  title="Choosing the Right Packaging Machine"
  excerpt="Learn how to select the perfect packaging machine for your production line."
  category="Packaging"
  author="Excelpack Machines"
  publishedAt="20 July 2026"
  readingTime="5 min read"
/>
```

## Used In

- Homepage Resources
- Blog Listing
- Related Articles
- News & Updates
