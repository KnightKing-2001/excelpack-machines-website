# Breadcrumbs Component

## Purpose

Navigation trail component for deep website pages.

## Features

- Home link support
- Custom separators
- Dynamic items
- Current page indicator
- Icons support
- Accessible navigation

## Usage

```tsx
<Breadcrumbs
  items={[
    {
      label: "Products",
      href: "/products",
    },
    {
      label: "Machine",
    },
  ]}
/>
```
