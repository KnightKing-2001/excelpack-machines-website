# Mobile Navbar Component

## Purpose

Responsive mobile navigation component.

## Features

- Hamburger menu
- Open/close state
- Logo support
- Navigation links
- CTA button
- Touch-friendly controls
- Keyboard accessible
- ARIA expanded support

## Usage

```tsx
<MobileNavbar
  items={[
    {
      label: "Products",
      href: "/products",
    },
  ]}

  ctaLabel="Contact Us"
/>
```
