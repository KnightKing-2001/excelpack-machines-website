# Motion Components

Reusable animation wrappers.

---

## Components

### AnimatedSection

Used for:

- Homepage sections
- Page blocks
- Content areas

### AnimatedCard

Used for:

- Product cards
- Industry cards
- Blog cards

### AnimatedContainer

Used for:

- Grid animations
- Lists
- Multiple cards

---

## Example

```tsx
<AnimatedSection>
  <Heading>Our Machines</Heading>
</AnimatedSection>
```
