# File Upload Component

## Purpose

Reusable file upload component for documents and attachments.

## Features

- Click to upload
- Multiple file support
- File validation
- File size limit
- Preview selected files
- Disabled state
- Error state
- Success state
- Accessibility support

## Usage

```tsx
<FileUpload
  label="Upload CAD Drawing"

  accept=".pdf,.dwg"
/>
```
