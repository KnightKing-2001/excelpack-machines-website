# Select Component

## Purpose

Reusable dropdown component for selecting one option.

## Features

- Label support
- Required indicator
- Placeholder
- Helper text
- Error state
- Success state
- Disabled options
- Accessibility support

## Usage

```tsx
<Select
  label="Industry"

  placeholder="Select Industry"

  options={[
    {
      label: "Pharmaceutical",
      value: "pharma",
    },
    {
      label: "Food Packaging",
      value: "food",
    },
  ]}
/>
```
