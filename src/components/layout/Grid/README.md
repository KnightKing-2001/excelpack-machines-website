# Grid Component

## Purpose

Responsive grid layout system.

## Features

- Responsive columns
- Standard spacing
- Flexible layouts
- Tailwind based
- Reusable across pages

## Columns

Available:

- 1
- 2
- 3
- 4
- 5
- 6

## Gap

Available:

- none
- sm
- md
- lg
- xl

## Usage

```tsx
<Grid
  columns={3}

  gap="lg"
>
  Content
</Grid>
```
