# Divider Component

## Purpose

Reusable separator component.

## Features

- Horizontal divider
- Vertical divider
- Multiple strength variants
- Semantic separator role
- Custom styling support

## Orientation

Available:

- horizontal
- vertical

## Variants

Available:

- default
- strong
- subtle

## Usage

```tsx
<Divider />

<Divider variant="strong" />

<Divider orientation="vertical" />
```
