# Section Component

## Purpose

Reusable page section wrapper.

## Features

- Consistent spacing
- Background variants
- Responsive friendly
- Semantic section element
- Custom class support

## Variants

### Spacing

- none
- sm
- md
- lg
- xl

### Background

- default
- muted
- dark
- primary

## Usage

```tsx
<Section
  spacing="lg"

  background="muted"
>
  Content
</Section>
```
