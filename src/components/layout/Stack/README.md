# Stack Component

## Purpose

Flexible flexbox spacing component.

## Features

- Vertical layouts
- Horizontal layouts
- Consistent spacing
- Alignment control
- Justification control
- Responsive friendly

## Direction

Available:

- vertical
- horizontal

## Gap

Available:

- none
- xs
- sm
- md
- lg
- xl

## Usage

```tsx
<Stack gap="lg">Content</Stack>
```
