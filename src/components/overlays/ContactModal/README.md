# ContactModal Component

## Overview

ContactModal is a reusable enquiry/contact dialog built on top of the Modal component.

It provides a consistent container for customer communication workflows.

---

## Features

- Reusable contact container
- Modal-based presentation
- Responsive layout
- Ready for form integration
- TypeScript support

---

## Usage

```tsx
<ContactModal open={open} onClose={() => setOpen(false)}>
  Contact form content
</ContactModal>
```
