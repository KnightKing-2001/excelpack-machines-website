# Excelpack Machines Website

Official website for Excelpack Machines.

## Tech Stack

- React 19
- Vite 8
- TypeScript 6
- Tailwind CSS v4
- React Router 7
- Framer Motion
- Axios
- Zustand
- React Hook Form
- Zod

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
